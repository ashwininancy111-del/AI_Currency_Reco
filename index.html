About the Project

AI-Based Currency Recognition with Voice Assistant is an intelligent and accessible system developed to recognize Indian currency denominations using Artificial Intelligence and Image Processing techniques.

The system allows users to upload a currency image or capture a currency note using a webcam. The captured image is processed by the AI model, which analyzes the visual features of the note and identifies its denomination.

After recognition, the detected currency value is displayed on the screen and can also be provided through voice output. This makes the system particularly useful for visually impaired users by providing an easy and accessible way to identify currency notes independently.
